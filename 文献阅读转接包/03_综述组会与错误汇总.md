# 综述、组会与错误汇总

## 1. 与逐篇学习稿的关系

每次独立阅读对话另生成三份辅助成果：`01_本次综述.md`、`02_本次组会.md`、`03_本次错误汇总.md`。同次多篇时按W编号标清来源，跨对话不合并归档。

NEWstudy是主要学习入口，必须独立讲懂本篇；三份辅助文件可复制、提炼、重新组织相关内容。**不能因为某个内容已在综述或组会出现，就将它从NEWstudy中删除或只留链接。** 内容复用时核对数字、条件和结论一致，重要纠正同步到该次受影响文件，保留更改原因及用户批注。

只把不同用途的产物分别组织，不拆散学习所需的逻辑。NEWstudy不需包含讲稿或完整错误台账，但必要的证据解读、缺点与原文错误提醒仍就地说明。

## 2. 本次综述

围绕本次已读文献组织问题、方法、证据、联系、分歧和课题启发；只有一篇时写结构化理解与分析，不强凑横向比较。可用简短、带条件的主要结论帮助复习，内容不足不凑条数。

各篇交代研究对象、背景与缺口、核心贡献、方法理由、数据和实验、主要结果、优点、局限、替代解释及分析性心得。可以从NEWstudy提炼；不再以复述多篇摘要代替综合，不替用户虚构个人经历。

跨篇比较先对齐对象与部件、温度/应力/工况、缺陷与劣化阶段、物理量与采样、数据和划分、指标定义/基线/不确定性、在线及迁移条件。讨论共同问题、方法与假设差异、证据强弱、相互矛盾和待验证缺口。不同实验不能拼成同一实验，指标和条件不可比时不直接排名。

只有实际读取或可核查的材料才能支持横向判断；哪些仅有笔记或摘要、哪些缺失要如实说明。观点和关键数字标W编号、页码/图表/公式位置；跨历史档案引用还带目录。不能凭一篇文献宣称领域共识。

课题关联按[01](01_研究主题与任务目标.md)的实际相关子要求展开，可使用“项目子要求｜文献证据与位置｜支持程度｜缺口或迁移条件”简表。支持程度区分直接支持、部分支持、未涉及、证据不足；直接支持具体子项不等于项目整体达标。涉及时保留应力来源与分布、微观指标、宏观参量、映射、单调性、阶段区间和自适应阈值的依据及验证条件。

核心证据可简列观察归属、条件/指标/单位/数值、原文位置、核查状态和限制，便于统一复核。必要时沿用W02-E01等证据编号，并同时指出档案位置；不同对话的同W证据号不能当作天然同一记录。无需重复整篇教学，也不以证据表替代NEWstudy必要解释。

如另行检索文献，记录关键词、日期、范围、纳入和排除理由及实际访问范围。普通比较和检索记录不自动构成系统综述或Meta分析。综述不是无边界的扩展检索授权。

## 3. 本次组会

默认中文，保留必要英文术语；听众按研究生新生和课题组讨论考虑。未提供时长时给可伸缩提纲，不擅自规定分钟数。默认提供基础提纲、推荐图表、讨论问题和参考回答；用户明确要求时再补逐页内容、讲稿或PPT。

讲述顺序围绕“研究问题→方法与选择理由→证据与结果→局限→课题启发”，聚焦核心信息，但保留改变结论含义的条件。可从NEWstudy复制必要讲解，让组会稿也能使用，不要求用户因文件分工反复查找。

每张推荐图表说明原文位置、展示目的、读法和边界。核心论断给出可追溯来源；未核查或冲突内容明确作为待验证主张或讨论问题，不作为确定结论。区分作者观点、助手分析和迁移建议，不用声望替代论证。

问答提供问题、参考答案与依据；无答案的明确说明，不能为凑问答编造。问题与答案可以同时出现，无需故意隐藏答案。可建议复述或计时排练，但未实际进行不声称已讨论或排练。生成提纲不等于PPT制作完成，提出复现步骤不等于已复现；如列复现计划，注明数据、代码和条件。

交付前对照NEWstudy、综述和原文，核对数字、术语、条件与结论；汇报压缩不能删去支撑结论所必需的依据。

## 4. 本次错误汇总：记录范围

集中记录**原文错误或疑点**，不是把所有不足、学习疑问都称为错误。论文未验证低温工况、未开展某类应用、适用范围有限等研究局限，在NEWstudy及组会分析；公式矛盾、数值不一致、单位或编码问题等进入本汇总。

确认错误需有原版面、数学定义、量纲、维度、文内对照等依据。信息不足、表达含糊或助手未理解时标“疑点待核实”，不能定性为错误。不要猜错误一定出在代码、排版或实验哪个环节。

原文无已确认错误时如实写“本次核查范围内未发现已确认错误”，并单列仍存在的疑点（如有）；不能保证论文没有错误，也不为填文件编造条目。

## 5. 每条记录必须包含的内容

可用逐条短记录，避免为了宽表牺牲可读性；每条均包含以下字段：

| 字段 | 内容要求 |
| --- | --- |
| 位置 | W编号、PDF页序；存在印刷页码时一并写出，另给章节、公式号、图表号或可定位关键原句 |
| 问题与依据 | 保留原文值、公式或原句，说明为何判错；区分已确认原文错误和疑点待核实 |
| 影响 | 影响理解、数值结论还是复现，是否影响主要结论或课题判断 |
| 原文修订情况 | 是否查到作者正式勘误/修订及可靠来源；没有证据时写“未确认正式修订”，不能写成确定不存在 |
| 学习文件处理情况 | 已纠正、仅加注、未修改或尚未处理；指明改了什么、依据是什么，链接当前NEWstudy及其他受影响文件的具体位置 |

还应注明记录/更新日期、具体处理状态和必要修改原因。位置暂不可确定时写明缺失及原因，不填猜测页码。

## 6. 状态标记与修改边界

**原文是否得到正式修订，与我们的学习文件是否得到纠正，是两个独立状态，必须分别记录。** 对未修改或尚未解决的条目使用醒目的文字加符号标记，不能只依赖颜色：

> **🔴 未修改｜正确值未知：仅标注原文冲突，不提供推测值。**
>
> **🔴 尚未处理｜学习文件仍待更新：写明受影响位置与原因。**
>
> **🟠 仅加注｜已解释问题，但无法确认正确公式。**
>
> **✅ 学习文件已纠正｜写明纠正依据与位置；原始PDF未改动。**

疑点同时标明“疑点待核实”，不能仅靠图标断言错误已确认。标记应符合真实处理：只记录进汇总，不等于已经给学习稿加注；只加注，不等于修正了公式或结论；记录完成，不等于问题解决。

保留原值，没有可靠依据不擅自填正确实验值。若展示标准数学定义或按表复算值，明确其身份及假设，不能称之为作者正式修订或真实实验结果。原文有多种可能解释，不为了填表擅选一个。获得可靠修订后保留此前记录、修改理由及日期，更新相关学习文件；不覆盖原始PDF。

完成一般核查后仍未找到勘误或补充材料，标明状态即可继续阅读。不因用户曾优先要求查勘误而无限追查、反复让用户去查，也不让一个问题拖住全部阅读。受影响公式或值不作为已验证结论、排名或课题达标依据；后续任务确需精确值或实现时再说明阻塞并询问。

旧W01的指标冲突属于历史已标注、正确实验值未知的情况，不在本轮重新启动查误，也不因此修改旧文件。只有本次确实分析该文献时才按本次范围引用其历史问题。

## 7. 提问与同步

妨碍核心理解的疑点及时在对话中说明并询问；常规错误标注后能继续的部分自主完成，不反复请求同一项确认。更新一个数值或解释时检查本次NEWstudy、综述、组会是否也受影响，并更新处理状态。跨历史档案仅在用户授权修改旧档案时更新，不能为了同步去覆盖旧批注或旧结论记录。
