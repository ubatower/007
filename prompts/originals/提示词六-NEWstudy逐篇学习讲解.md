# 提示词六：NEWstudy逐篇学习讲解

确认日期：2026-10-18（北京时间）。本提示词依据用户本次明确要求整理，属于已确认、持续生效的新增要求，不是待确认提案。按用户要求与此前四份提示词放在同一目录；本文件是新编写的提示词，不冒充上传原文。以后从 `prompts/README.md` 进入阅读任务时必须一并应用，无需用户重复发送。

## 1. 任务与读者

请为每篇本次分析的文献，额外生成一份可独立学习的中文讲解。读者是刚入学的研究生，几乎没有科研经验与相关学术基础，**没有读过上传的原文，你的讲解就是读者第一次了解这篇文献**。不得假设读者已读过其他笔记、前面的聊天或其他论文。

核心任务是把一篇文献从头到尾思考、理解、分析后，压缩成读者能够学懂的解释：保留研究问题、方法的因果逻辑、必要条件、实验依据、结论及缺点，减少重复、术语堆叠和管理信息。压缩不能以删掉必要解释为代价；详细程度由理解需要决定，不追求固定字数，也不以篇幅长证明阅读充分。不能只做摘要翻译、条目拆解、批评清单或符号罗列，让读者仍不知道论文在做什么。

问题和答案可以放在一起。不要把“先看答案”当成学习失败的原因，不强制要求读者先答题、再另开一轮询问答案。教学问题用于组织解释，不用于阻断阅读。

## 2. 命名、数量与归档

1. 文件名严格采用 `NEWstudyW编号.md`，保留实际W编号的写法，例如 `NEWstudyW02.md`、`NEWstudyW03.md`。`W**`仅为当前文献编号的占位表达，不把星号写入文件名；不把多篇合成 `NEWstudyW02-W03.md`。
2. 一次阅读对话内，一篇文献对应一份NEWstudy文件。两篇W02、W03必须各自生成一份。每份文件原则上只分析当前这一篇文献，不能将两篇正文合并讲解。
3. 放在**本次阅读对话对应的日期目录内，与原有六份Markdown同级**。保留原有六份的名称与职责；NEWstudy是额外文件，不替换第六份，不改名为第七份或第八份。该次分析N篇文献时，Markdown成果为原有六份加N份NEWstudy。
4. 每次独立阅读对话分别建档，不把两次对话生成的阅读成果放在同一目录。即使同一天、同主题、同仓库、W编号连续，也不能据此合并。目录日期、NN、续读判断及不明时提问，沿用[每次阅读对话独立建档](../confirmed-additions/每次阅读对话独立建档.md)。明确属于同次对话的追问修订才更新该次文件。
5. 重读已编号文献时沿用其W编号，并放在本次独立重读目录；不能因文件名相同就覆盖另一对话的文件。跨对话编号规则仍按提示词三执行。
6. 在该次第五份清单中提供各篇NEWstudy的相对链接，便于定位。不得为了管理NEWstudy再新增逐篇子目录或平行阅读目录。
7. 每份讲解**开头第一行写出原文献的完整标题**，可使用 `# 原文完整标题`。中文译名可在后面辅助理解，但不能替代原题名。不用管理元信息把标题和正文隔开。

示例仅说明结构，不代表此次已生成阅读成果：

```text
读文献/
  YYYY-MM-DD-01/                 # 一次阅读对话，分析W02与W03
    01_阅读心得与综述.md
    02_精简主题与凝聚结论.md
    03_阅读思路与教程.md
    04_必要知识点.md
    05_本次对话的文献排序W02-W03.md
    06_详细阅读总结与符号缩写说明.md
    NEWstudyW02.md
    NEWstudyW03.md
  YYYY-MM-DD-02/                 # 另一次阅读对话，另行建档
    ...                         # 该次六份文件及每篇各自的NEWstudy
```

## 3. 讲解方式与完整逻辑

采用用户认可的试讲方式：从一个具体、能引起理解需求的小问题切入。例如W02可从“没有见过某种轴承故障，模型凭什么识别它？”开始。这个问题是进入全文的入口，不能只回答这一点就省略论文其余核心内容。其他论文应选择它自己的核心问题，不能机械套用轴承或零样本主题。

按读者理解所需的顺序连贯展开，必要时用短段、小例子、对照表或简图辅助；以下是内容要求，不要求照搬为固定栏目：

- 先交代研究对象是什么、实际想解决什么困难、为什么值得研究；必要的设备、数据和任务常识先解释。
- 讲清作者已有的信息、缺少的信息，以及希望模型从什么输入得到什么输出。对训练、测试、预测目标等初学者易混概念及时解释。
- 逐步走通方法：每一步接收什么、做什么、输出什么，为什么需要这一步，如何连接下一步。先给直观解释，再补必要的术语和数学表达，不能靠算法名称代替解释。
- 把关键概念之间的关系讲清楚：哪些是原始测量，哪些是数据表示，哪些是要预测的含义，哪些是最后的类别或决策。明确哪些概念相近但不同，哪些是包含关系。
- 解释作者怎样验证方法：数据从哪里来、做的是什么实验、训练与测试如何划分、与谁比较、评价指标到底在评价什么。结果用普通语言说清，并保留关键条件。
- 说明结果支持什么结论，哪些地方做得好、哪些是缺点、哪些问题还没有解决；不能把读者不懂的限制语句堆在结尾而不解释其实际影响。
- 以自己的分析说明读完后应当理解的主要思想、适用条件和可以借鉴的地方。课题联系有助于理解时自然说明，但不另堆项目指标对照和管理表。

为帮助理解而构造的小数字、小场景必须标明“教学示例”，不能冒充原文实验、数据或作者原话。举例要有对应解释，不只给计算结果。

## 4. 从两次试讲反馈形成的必查解释点

以下反馈既约束W02的讲解，也用于检查其他文献是否存在同类理解缺口。其他文献没有使用这些方法或数据时，不强行加入无关内容。

| 用户曾经卡住的问题 | 讲解必须做到 |
| --- | --- |
| “CWRU实验”是什么实验？ | 首次出现数据集或实验简称时，说明可核实的名称、来源、研究对象、数据怎样获得，以及本论文是复用公开数据还是自行开展实验。W02中的CWRU指Case Western Reserve University的轴承数据；解释轴承故障分类实验，不能只写缩写或让读者误以为是风机现场实验。 |
| CNN与残差CNN是什么，一样吗？ | CNN解释为卷积神经网络，并说明它在本文输入、特征提取与预测中的作用。残差CNN属于CNN的一类，解释跳跃连接让输入信息绕过部分变换参与后续计算的含义及用途；不能将二者写成完全相同或互不相关的方法，也不保证残差结构必然更准确。其他模型同样说明基本含义和相互关系。 |
| “把完整类别拆成可共享属性”是不是RGB的三个变量？ | 明确区分测量变量、RGB输入通道、语义属性和完整故障类别。W02把信号编码进RGB图像，与把完整类别描述为位置、损伤尺寸或等级、工况等可共享属性，是不同步骤；不能写成R、G、B分别就是三个故障属性。用一个完整类别及其属性组合解释“共享”，说明跨类别共享的是属性取值及其可学习关系。 |
| 欧氏距离是不是预测概率？ | 明确距离是向量之间差异的度量，概率表达模型对某种输出的预测。解释概率向量、类别属性描述向量如何参与匹配，以及距离较小为什么对应更接近的候选类别；若给简化算例，标明教学示例，不能把距离值说成概率。 |
| “KAT轴承数据”是数据的一种还是全部？ | 说明W02所用KAT是特定的Paderborn University轴承数据来源称谓，论文使用其中选定的数据或类别；它不代表所有轴承数据，也不意味着使用了该数据源的全部内容。全称无可靠依据时不猜写。其他数据集同样区分数据源、作者选用子集和更广泛的数据总类。 |
| 未见属性值、未定义故障以及已见/未见混合问题算什么？ | 可以直接写为“缺点”或“尚未解决的问题”，并解释影响。W02依赖已有属性体系及候选类别描述，不能自动识别训练中从未学到的新属性值或完全没有定义的故障；其论文实验尚未解决真实环境中已见与未见类别混合出现的完整识别问题。解释已见/未见相对于训练类别而言；不要把“一个新的数据样本”与“一个未见类别”混为一谈。区分原文已证明的限制、未验证情形和自己的推断。 |
| “轴承分类成绩”是什么？ | 用具体指标名及普通语言解释，例如“测试样本的故障类别判对了多少”。交代评价对象、任务划分和平均方式，不只给一个百分数；必要时用假设100个样本的教学例子解释。不能把分类准确率自动当成早期缺陷检出率、现场泛化能力或剩余寿命预测成绩。 |

所有新出现的专有缩写和关键术语，都应在需要它的位置解释中文含义、可核实的英文及其作用。不得用一个读者不懂的术语解释另一个术语。说明后可使用简称，不需要反复机械重复同一句定义。

## 5. 跨文献引用与事实边界

每份文件独立可读。允许引用其他文件的分析，例如另一篇文献采用同类方法时，可提供相关文件与W编号的相对链接，说明可比之处；**必须在当前文件再次解释理解所需的概念和方法**，不能只写“见W01”“前面已经说过”或让读者自行补读才能理解。

引用服务于当前文献，不扩展成另一篇完整分析。核实引用来源与适用条件，不把别篇的实验结论或实现细节移植为本篇事实。

沿用[原文错误标注规则](../confirmed-additions/原文错误标注.md)：能确认的错误直接标明并解释影响，仅有疑点的注明未核实，保留原值、不自行补造正确值。与学习有关的缺点和错误解释可以放在相应段落；查误过程及管理记录放到原有相应文件中。遇到妨碍正确讲解的困难及时向用户说明并提问，不悄悄跳过，也不长时间独自无效追查。

## 6. 公式、图片、矩阵与未来Word

- 本文件先以UTF-8 Markdown生成，作为以后用户需要Word时的内容基础。**生成Markdown之后不得自动转换Word；必须等待用户明确的转换指令。** 过去某次转换授权不自动成为每次导出的要求。
- 从直观讲解开始，不先堆公式。公式、图片、矩阵按理解需要从原文获取；无需这些就不必调用或为了形式完整硬加。确有教学需要的自拟表达应标明教学用途，并核对正确性。
- 使用原文公式、图片或矩阵时，解释它在这一步说明什么，给出必要的页码、图号或公式号定位；不能只贴图让读者自己猜。符号在使用位置简明解释，避免无关推导。
- Markdown公式使用能正确显示的数学格式，检查上下标、括号、维度与矩阵元素；使用图片时保证清晰、标签完整、矩阵对角元素及其他元素不缺失，不为非方阵虚构对角线。无法可靠表达时说明困难并协商，不交付看似完整但含义错误的数学内容。
- 为后续转换保留清楚的标题层级、正文顺序、图注与有效引用。若使用图片，确保交付中的图片实际可访问，不能只链接到会丢失的临时渲染路径。此条不授权自动生成Word或另建平行文献管理目录；需要新增资源存放约定且现有规则不能涵盖时先说明并询问。

## 7. 学习文件中禁止加入的内容

NEWstudy文件不包含以下栏目，也不能换一个名称把相同的管理或审计内容放进去：

- 材料身份、权限与页码约定。
- 本轮完成状态。
- 阅读范围、证据标准与本次边界。
- 项目对照口径。
- 唯一主要证据表。
- 按用户要求优先查误：访问记录。
- 疑问队列与下一步。
- 快速恢复入口。

这些事项按原有六份文件各自职责处理。上述排除不妨碍在正文中解释实验条件、证据支持范围、原文错误、缺点和必要来源定位，这些与学懂文献直接相关。

## 8. 交付前内部核对

以下用于生成者自检，不复制成NEWstudy正文的审计章节：

1. 文件名、W编号、原文标题对应；本次每篇各有一份，且均在正确的独立对话目录。
2. 原有六份保留；没有跨对话合并、跨文件覆盖或用一份多文献讲解代替逐篇交付。
3. 假设读者从未读过原文，仍能理解研究对象、问题、输入输出、完整方法、实验、结果含义与缺点。
4. 术语首次出现已解释；逐步因果关系清楚；已防止测量变量/属性/类别、概率/距离、数据源/子集、分类指标/课题指标等混淆。
5. 引用其他文献时已在本文件重讲必要内容；教学例子与原文事实可区分；没有为压缩篇幅省略核心内容。
6. 必要数学或图片可读、完整、与原文对应；没有无需求堆放公式图表，也没有自动生成Word。
7. 八类禁止内容及同类管理信息均未混入学习正文；必要的缺点与原文错误仍已直接解释。
